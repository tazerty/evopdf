EvoPdf portable mode

While this file sits next to evopdf.exe, EvoPdf keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the EvoPdfData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move EvoPdf with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\EvoPdf and
%LOCALAPPDATA%\EvoPdf) instead. If EvoPdfData can't be written (for example on a read-only
drive), EvoPdf says so and uses the per-user folders instead.
